## Rules and state model

The game engine keeps stock, waste, four foundations, seven tableau piles, score, elapsed time, move count, options, a bounded undo history, and one Magic charge per deal. A card can move to a tableau pile only in descending rank with alternating color; an empty pile accepts a King. Foundations build upward by suit from Ace to King. Drawing uses the selected one-card or three-card mode, and the waste returns to the stock when it is empty. Face-up sequences move together, and uncovering a hidden tableau card flips it face up. Daily deals are deterministic by local calendar date; the calendar can start today's or a previous date's deal, marks completed dates, and tracks monthly completion milestones. Future dates stay locked. Winning records daily completion and opens the source-matched full-screen result, where New Deal starts a fresh shuffle.

## Audio and animation status

The original game's audio could not be isolated from the mixed promo and gameplay recordings. The web build now uses captured candidate crops for tableau moves, stock draws, foundation rewards, Auto Collect, and the win transition; taps, stock recycle, and invalid moves still use synthesized sound. A separate recycle event is sent through the procedural flip fallback because the observed 98.61 s transient could also be the first draw after recycling. Every captured crop is from a mixed third-party recording rather than a clean original stem, so it is source-aligned evidence, not proof of exact sound identity. The source Settings page exposes one Audio switch, which mutes the effects bus and any optional music bus. The experimental generated music bed remains off by default and has no user-facing toggle because no continuous gameplay music was confirmed in the available recording. Audio starts after a user gesture and queues cues while a pending `AudioContext.resume()` completes. Mobile Chrome E2E verifies cue decoding, sample-level output gain, and setting changes; it does not certify physical-phone-speaker playback.

The interface animates the initial deal, stock-to-waste draw, card landing, drag preview, win treatment, and sound cues. In the 60 fps gameplay capture, the first stock-draw frame appears at source time 23.2167 s with the 6♥ already face up; it reaches the waste position by 23.35 s, an eight-frame 133.333 ms flight. The mobile replica now uses a 133.333 ms linear stock-to-waste flight and displays the face immediately. Winning displays score, time, moves, and a best-score marker; daily wins are recorded in the calendar.
