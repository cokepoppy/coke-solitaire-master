# Theme gallery source pixel audit

The source is the 884×1920 portrait gameplay recording `gLd0HXtDt5I.mp4` (SHA-256 `56489d4aac9256d15de461d236a990df361621363fdc2904341a0e8e9cb64928`). The audited gallery frames are 323 s / PTS 4,961,280 (Backgrounds), 325 s / PTS 4,992,000 (Face Style), and 327 s / PTS 5,022,720 (Back Style). Each Playwright capture uses a 442×960 CSS viewport rendered at 2×, with no image rescaling. The comparison ignores the iOS home-indicator rectangle at `(280,1885,330,25)`.

`backgrounds.json`, `faces.json`, and `backs.json` contain the raw source/rendered PNG hashes and the complete pixel-difference report from `tools/compare_screenshots.py`. The corresponding source-frame hashes are `c0fc5f2018d179b2d890f9e9b0e1d475ca9363b1235a1c38ec9fef865fabd121`, `8e1d5a22f7a1c0e6594196ae5f5eb013dedb5b5bc6d3af6d7c9ff341c85b244e`, and `7bd63feaacc18412cf3ec5763f9cd40c382e23c552e94db795d8146b481c000f` respectively.

The 72 affected artwork PNGs contained an HDTV ICC profile that caused Chrome color management to transform the already source-aligned RGB channel samples. They were re-embedded with the sRGB profile using `sips -e`; decoded RGB pixels were verified unchanged. The PNG SHA-256 values are committed in `tests/fixtures/source-art-srgb-hashes.json`, and Playwright verifies every fetched file.

The Back Style gallery also had a layout and scale mismatch: each 200×300 source preview had been rendered at 212×318 with an extra CSS border. Dedicated source crops now render at their original 200×300 size, including the selected Ruby outline and check. The eight gallery positions are asserted by E2E.

The baseline measurements were captured before changing color profiles and back-gallery layout. MAE is mean absolute RGB error over the 884×1920 images after zeroing the ignored OS-only indicator region; video compression and browser rasterization still contribute some error. The screenshots are generated by the `source-sized background gallery`, `source-sized face gallery`, and `source-sized card-back gallery` Playwright tests.

The selected background's green check badge in the 323 s frame extends beyond the tile's lower-right edge. The web tile previously clipped it and placed it up and left. The selected tile now allows the badge to overflow, places its source-sized 64×64 px box at `(720,924)`, and uses a top-to-bottom green fill matching the captured badge. In the `(700,900)` 110×110 check region, MAE falls from `27.094683` to `10.726088`; over the full selected tile it falls from `8.454044` to `6.976496`. The full gallery masked MAE falls from `7.578898` to `7.462810`. `backgrounds.json` records the latest region measurements and screenshot hashes.
