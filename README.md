# Solitaire Master Mobile

An installable, mobile-first web adaptation of Hungry Studio's classic Klondike solitaire.

This repository was empty when cloned. The `main` branch begins with this project baseline; gameplay implementation is developed on a feature branch and merged back after browser interaction acceptance.
